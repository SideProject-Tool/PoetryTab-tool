Poetry-Tab 隐私政策

更新日期：2026-09-20

我们收集什么

Poetry-Tab 不收集任何个人身份信息，不含任何统计、追踪或广告组件。

扩展与网页版会将你主动创建的内容——收藏分组、书签、常用网站、iframe 小部件、界面设置（主题/搜索引擎/诗词分类）——以 JSON 形式保存到你对应的云端存储空间中。

数据存在哪里

你的数据存储在开发者自有域名 sync.pathmemos.com（Cloudflare Workers + R2 对象存储，位于 Cloudflare 全球网络）之下的独立存储路径中，路径以你的用户 ID 命名。服务器自动保留最近 5 个历史版本用于误操作恢复。

数据如何被访问

用户 ID 是你数据的唯一访问凭证：在浏览器扩展或网页版输入同一 ID，即可读写同一份数据。请求使用内置令牌进行接口鉴权。除此之外，任何第三方（包括开发者）的网页都无法读取你的数据。

我们不做什么

不销售数据、不做用户画像、不投放广告、不嵌入第三方统计脚本、不请求通讯录/浏览历史等浏览器敏感权限（扩展权限仅为空权限列表与自身同步域名）。

数据删除

你可以随时通过页面上的联系方式请求删除全部云端数据；或停止使用并清除浏览器本地数据（扩展的 localStorage）。

联系方式

如有隐私相关问题，请通过 Chrome Web Store / Edge Add-ons 商家页面的「支持联系方式」与我们联系。

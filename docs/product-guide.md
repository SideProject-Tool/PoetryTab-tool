# Poetry-Tab 产品手册（业务功能总览）

> 面向接手者/运营：不读代码即可理解产品的全部功能与行为规则。
> 技术实现见 `architecture.md`；同步与数据细节见 `sync-and-data.md`；仓库操作见根目录 `AGENTS.md`。

Poetry-Tab 是一个**新标签页产品**（Chrome 扩展 + 网页版同一套功能）：每次打开新标签页看到一首古诗词，下方是可自由组织的**收藏看板**；一个「用户 ID + 密码」账号在所有设备间同步全部数据。

---

## 术语

| 术语 | 含义 |
|---|---|
| 卡片 | 看板上的一个区块，共两种：**分组**卡、**iframe 小部件**卡 |
| 列 | 卡片的纵向容器；看板由 2-5 列等宽列组成（手机为单列） |
| 分组 / 子分组 | 分组 = 顶层卡片；分组内可建**一级子分组**（卡片内以标签页形式展示，共两级） |
| 磁贴 | 卡片内的书签方块（图标 + 名称），点击直达网址 |
| 槽位 | 云端布局的固定 5 个列位（各设备按自己的列数取用） |

---

## 一、诗词区（页面顶部）

- 每次打开新标签页展示一句/一首诗词，**点击诗词区域换一首**；同一轮内不重复，读完一轮自动重新洗牌
- 12 个分类（诗词、文学、哲学、动画、漫画、游戏、影视、网易云、原创、网络、其他、抖机灵）在设置中任意勾选，**至少保留一个**
- 「🔍 查出处」跳转当前搜索引擎查询该句出处
- 超长诗句单行省略截断，页面高度恒定不跳动
- **诗词区留白**（设置 → 外观）：设定诗词区的最小高度（自动 / 240 / 360 / 480 / 自定义 0-600px），诗词在区域内上下居中，下方看板随之整体下移；偏好随账号同步
- **卡片白底**：所有分组/iframe 小部件卡片固定白色底色、深色文字（双主题一致），在自定义深色页面底色上同样清晰
- **页面底色**（设置 → 外观）：按当前生效主题独立配色——浅色主题 14 个浅色预设、深色主题 8 个深色预设，或取色器/色号（#RGB/#RRGGBB）自定义；「恢复默认」回到主题底色；两套底色随账号同步
- 诗词顺序与进度存在本地（不占云端空间），按账号无关联

## 二、搜索

- **默认隐藏**（给诗词区留白）；按 `S` 或点右上角 🔍 呼出，`Esc` 或再点收起
- 搜索自己的收藏：实时匹配书签的**标题、网址、所在分组路径**，支持**拼音全拼与首字母**（`weibo` → 新浪微博、`blbl` → 哔哩哔哩；拼音库按需加载）
- 结果中 ↑↓ 切换、Enter 打开、Ctrl+点击新标签打开；**打开后自动清空关键词**便于连续跳转
- 收藏搜索无命中时，回车（或点提示行）用当前设置的搜索引擎（百度/Google/Bing/DuckDuckGo）网页搜索该关键词，新标签打开；搜索引擎设置同时决定诗词「🔍 查出处」的跳转目标

## 三、收藏看板（核心）

### 布局模型（v2 列式）

- 卡片按**列**排布，每列等宽；列与列间距 14px
- **列数**：设置 → 外观 →「看板列数」，`自动`（按窗口宽度 5/4/3/2 列）或固定 `2/3/4/5` 列，偏好随账号同步
- **手机（<640px）恒为单列满宽**，按「列序 × 列内顺序」排列，不支持拖拽
- 卡片高度全部**随内容自适应**（分组卡）；例外：iframe 卡高度由用户设定
- 视口外的卡片自动跳过渲染（性能优化），滚动到位即显示

### 拖拽排序

- **按住卡片标题栏拖动**：列内上下换位、跨列移动
- 拖动中：被拖卡以虚线占位，其余卡片**实时让位**；松手一次保存到云端
- 触发阈值 6px（避免误伤点击）；仅多列模式可用

### 卡片一：分组

- 自建分组卡；卡片内书签磁贴完整展开
- **子分组（仅一级）**：有子分组时卡片只显示**子分组标签页**（不显示「全部」、分组直属的书签不再展示）；子分组下不能再建子分组——任何视图下「新建子分组」都创建为**分组顶层的同级子分组**（书签导入可产生任意深度层级，其中更深的文件夹经浏览浮层只读查看，不再产生新深层级）
- **批量移动**：管理工作台勾选多条书签/子分组 → 「移动到…」选择目标分组或子分组，一次跨层级移动（A→B、A/A1→A/A2 均可，自动防成环）
- **管理工作台**（卡片 ⋯ 打开）：桌面端左右分栏——左侧分组树（子分组的创建/重命名/删除，含内容的删除需二次确认），右侧列表；手机端自动全屏、分组树变为顶部标签 chips
- 列表交互：**点行展开行内编辑**（书签为标题+网址两栏，Enter 保存/Esc 取消）；删除/打开等低频操作收进行尾 ⋯ 菜单；按住行首把手**拖拽排序**（搜索过滤时暂停）；工具栏提供**搜索**（按标题/网址过滤当前列表）
- **子分组排序**：左侧分组树中按子分组行首把手上下拖动，顺序即卡片标签页顺序
- **批量收录**：工具栏「批量」展开多行录入层，一行一条，支持三种写法——`标题 网址`、纯 `网址`、`[标题](网址)`；实时显示识别条数；一次入库只触发一次保存
- **自动取名**：收录时标题留空，先以网址入库，后台经云服务取回网页 `<title>` 自动替换（取不到则显示网址）
- 收录时自动过滤 `javascript:` 等不安全协议；纯中文词组会被当作中文域名收录（与单条输入行为一致）

### 卡片二：iframe 小部件

- 任意网站直接内嵌为新标签页区块（监控面板、文档站、日历等）
- 操作收进右上角 **⋯ 菜单**：
  - **高度**：预设档位（240 / 420 / 600 / 800）或**自定义输入**任意像素值（200-2000，回车生效，越界自动回退），存入该部件数据、随账号跨设备同步
  - 重新加载 / 新窗口打开 / 删除小部件
- **懒加载**：滚入视口（±300px）才加载；页面会话内不重载（刷新页面才重载——浏览器安全模型不允许跨页面保活）
- 部分网站禁止内嵌（X-Frame-Options）会显示空白，菜单「新窗口打开」兜底；网页版（https）下 http 站点会被浏览器混合内容策略拦截，同样以「新窗口打开」兜底

### 其他看板能力

- **删除撤销**：删除书签/分组/小部件后底部出现「已删除 · 撤销」提示，**6 秒内**可一键恢复
- **卡片显隐**：设置 → 外观，每张卡片可隐藏/显示（隐藏后再显示，位置不变），偏好随账号同步
- **空看板引导**：账号内无任何内容时显示引导卡（指向 ＋ 新建与书签导入），有内容后自动消失
- **书签导入**：
  - 扩展端：设置 → 导入与备份 →「导入浏览器书签」（读取浏览器书签树）
  - 网页版/扩展：导入浏览器导出的书签 HTML 文件（Netscape 格式，Chrome/Firefox/Edge 通用）
  - 导入**追加**为新分组（不覆盖现有数据）；相同网址（域名+路径转小写、去末尾斜杠，忽略协议与 query/fragment）自动跳过并报告「新增 N / 跳过 M」
- 右下角 **＋ 悬浮按钮**：新建分组 / 添加 iframe 小部件

## 四、云同步（账号）

- **账号 = 用户 ID + 密码**，无邮箱、无验证码。ID 规则 2-32 位（字母/数字/汉字/`_`/`-`），密码至少 6 位
- 同一 ID 在扩展、任何设备浏览器上登录，看到的都是同一份收藏
- 修改 **700ms 防抖自动保存**；设置面板可手动「上传到云端 / 从云端恢复」（上传 = 立即保存，冲突仲裁态下等同选择以本地为准；恢复 = 无条件采纳云端，未同步的本地修改会被放弃）
- 服务端保留 **5 份历史快照**：设置 → 导入与备份 →「历史版本」查看，两步确认恢复（恢复动作本身也留快照，可再撤销）
- **导出/恢复 JSON 备份**：整份下载 / 整份替换上传——**密码丢失无找回渠道，备份是唯一自救手段**
- 同浏览器多标签页之间实时互通；多设备并发冲突时进入**强制仲裁**（详见 `sync-and-data.md`）
- 离线可用：本地缓存先渲染，联网后自动同步；数据未变化时拉取零流量（ETag 304）

## 五、设置（居中弹窗，三标签页）

| 标签页 | 设置项 |
|---|---|
| **外观** | 主题 · 搜索引擎 · 看板列数 · 诗词区留白 · 展示类别（12 分类）· **页面底色**（预设色板+自定义）· 卡片显隐 —— 所有选项控件直选直显，无二级展开 |
| **云同步** | 用户 ID（输入新 ID 回车切换登录）· 上传到云端 · 从云端恢复 · 打开网页版 · 退出登录 |
| **导入与备份** | 导入浏览器书签（扩展）· 导入书签文件 HTML · 导出备份 · 恢复备份 · 历史版本快照 |

## 六、快捷键

| 按键 | 行为 |
|---|---|
| `S` | 呼出搜索（焦点在输入框时忽略） |
| `Esc` | 收起搜索 / 关闭设置弹窗 / 清空搜索词 |
| `Ctrl/⌘ + 点击` | 搜索结果/磁贴在新标签打开 |

普通点击目标：扩展端一律新开前台标签页；网页版在当前页跳转（`Ctrl/⌘ + 点击` 新开标签）。

## 七、移动端行为（<640px）

- 看板单列满宽、上下排列，顺序与桌面列序一致
- 不支持拖拽排序（在桌面端调整）
- iframe 卡沿用设定高度（档位不变）
- 搜索经右上角 🔍 按钮呼出（无物理键盘快捷键）

## 八、隐私要点

- 密码**明文永不上传**：本地 PBKDF2(600k 迭代) 派生后以挑战应答登录，服务端只存派生结果
- 收藏数据存放于自建 Cloudflare R2，不经手第三方；无埋点、无追踪、无广告
- 登录链路无法探测 ID 是否存在（不存在的 ID 返回确定性伪盐，登录失败统一「ID 或密码不匹配」）；注册接口按设计会拒绝重复 ID（409 = 已被占用）
- 详细隐私条款：https://sync.pathmemos.com/privacy.html
